## Introduction

Most debiasing programmes succeed at one thing: [teaching]({{ 'teaching/' | relative_url }}) people to recognise a named bias immediately after a lesson. The more difficult question is whether that learning survives outside the classroom, when nobody labels the problem as "confirmation bias" or "anchoring". Research suggests that some short interventions—particularly interactive games and carefully designed training videos—can produce measurable improvements that transfer to new judgement tasks. However, the strongest evidence comes from programmes that make learners practise decisions, receive immediate [feedback]({{ 'feedback/' | relative_url }}), and later face unannounced problems rather than textbook examples. The overall picture is cautiously optimistic: transfer is possible, but it is neither automatic nor universal, and claims that a single intervention permanently eliminates bias are not supported by the evidence.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/31347444/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Debiasing Training Improves Decision Making in the Fieldby AL Sellier · 2019 · Cited by 182 — The results provide promising evidenc...</span></span></span>

## What short debiasing interventions have shown

One of the best-known programmes was developed by researchers including Carey Morewedge and colleagues. Participants completed either an interactive computer game or an instructional video that taught several cognitive biases relevant to intelligence analysis, including confirmation bias, the bias blind spot and the fundamental attribution error. Unlike many earlier studies, participants were tested not only immediately afterwards but again weeks later using different bias tasks.

The results were encouraging. Both formats reduced susceptibility to several biases immediately after training, and some improvements remained after follow-up [testing]({{ 'testing/' | relative_url }}). However, the interactive game consistently produced larger and more durable reductions than the instructional video. Rather than simply defining biases, the game placed players in situations where they repeatedly made judgements, experienced the consequences of biased reasoning and practised corrective strategies.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://journals.sagepub.com/doi/abs/10.1177/2372732215600886" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: journals.sagepub.com">[Sage Journals+2Medical Xpress]</a><span class="citation-popover" role="note"><span class="citation-popover-source">journals.sagepub.com</span><span class="citation-popover-snippet">Sage JournalsImproved Decision Making With a Single Training...by CK Morewedge · 2015 · Cited by 589 — Participants received a single tr...</span></span></span>

The important feature was not entertainment for its own sake. The game repeatedly elicited the very biases it aimed to reduce, then explained what had happened and allowed players to try again. This combination of experience, explanation and corrective [practice]({{ 'practice/' | relative_url }}) appears more effective than passive exposure to definitions alone.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://scholarsarchive.byu.edu/facpub/5661/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: scholarsarchive.byu.edu">[BYU ScholarsArchive]</a><span class="citation-popover" role="note"><span class="citation-popover-source">scholarsarchive.byu.edu</span><span class="citation-popover-snippet">BYU ScholarsArchiveMitigation of Cognitive Bias with a Serious Gameby NE Dunbar · 2017 · Cited by 31 — We conducted two studies to examin...</span></span></span>

Perhaps the strongest evidence for transfer came later when researchers tested whether the training influenced decisions in a setting where participants were not expecting a bias exercise. Graduate students received confirmation-bias training before or after analysing an unannounced business case modelled on the decision preceding the Space Shuttle Challenger disaster. Those who had received training were significantly less likely to adopt the inferior, hypothesis-confirming solution and instead generated more evidence that challenged their initial [assumptions]({{ 'assumptions/' | relative_url }}). Because participants were not explicitly reminded about confirmation bias during the exercise, the study provides unusually strong evidence that debiasing can influence real judgement rather than only laboratory test performance.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/31347444/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Debiasing Training Improves Decision Making in the Fieldby AL Sellier · 2019 · Cited by 182 — The results provide promising evidenc...</span></span></span>

## Why feedback beats passive awareness

Simply learning that cognitive biases exist rarely changes behaviour by itself. Many people readily acknowledge that confirmation bias or [overconfidence]({{ 'overconfidence/' | relative_url }}) affect human judgement while continuing to believe that they themselves are relatively immune—a phenomenon known as the bias blind spot.

Interactive interventions attempt to overcome this problem by making people experience their own errors. Instead of presenting a lecture, they require decisions, expose [mistakes]({{ 'mistakes/' | relative_url }}), explain why those mistakes occurred and immediately encourage another attempt. This creates several learning advantages:


<div class="content-enhancement content-enhancement--example" markdown="1">

* learners receive personalised evidence that they are susceptible to bias;
* corrective strategies are practised rather than merely described;
* feedback arrives immediately after the mistaken judgement;
* repeated examples encourage abstraction of a general reasoning strategy rather than memorisation of one example.

</div>

Studies comparing serious games with equivalent instructional videos suggest that this active learning process helps explain why games often outperform passive formats, even when both communicate similar information.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://scholarsarchive.byu.edu/facpub/5661/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: scholarsarchive.byu.edu">[BYU ScholarsArchive+2Sage Journals]</a><span class="citation-popover" role="note"><span class="citation-popover-source">scholarsarchive.byu.edu</span><span class="citation-popover-snippet">BYU ScholarsArchiveMitigation of Cognitive Bias with a Serious Gameby NE Dunbar · 2017 · Cited by 31 — We conducted two studies to examin...</span></span></span>

The same principle appears in broader educational research: transfer improves when learners repeatedly apply an idea across varied situations instead of only recognising it in the original teaching context. Debiasing interventions that embed feedback inside realistic decisions therefore align well with what is already known about transfer of learning.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://scholarsarchive.byu.edu/facpub/5661/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: scholarsarchive.byu.edu">[BYU ScholarsArchive]</a><span class="citation-popover" role="note"><span class="citation-popover-source">scholarsarchive.byu.edu</span><span class="citation-popover-snippet">BYU ScholarsArchiveMitigation of Cognitive Bias with a Serious Gameby NE Dunbar · 2017 · Cited by 31 — We conducted two studies to examin...</span></span></span>

## Can games teach judgement beyond laboratory examples?

A related line of research concerns misinformation rather than traditional decision biases. The online game *Bad News* asks players to create misleading content themselves, exposing them to weakened examples of manipulation techniques such as emotional language, conspiracy narratives and impersonation. The intervention draws on psychological inoculation theory: practising recognition of misleading techniques before encountering them in real life may increase resistance later.

Experimental studies have found that people who played the game became better at identifying common misinformation techniques in novel examples presented afterwards. Replication studies with [control groups]({{ 'control-groups/' | relative_url }}) generally support these improvements, although the measured effects are typically modest rather than dramatic. The evidence suggests that the intervention teaches recognition of manipulation strategies rather than broad scepticism towards all information.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nature.com/articles/s41599" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nature.com">[Nature+2PMC]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nature.com</span><span class="citation-popover-snippet">wrong: the correction of misinformation...Read more...</span></span></span>

This illustrates an important distinction about transfer. Successful interventions often teach deeper patterns—for example, recognising emotional manipulation or searching for disconfirming evidence—rather than memorising individual false claims. When later examples differ in content but use the same underlying strategy, learners have a greater chance of recognising the problem.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.sdmlab.psychol.cam.ac.uk/research/bad-news-game" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: sdmlab.psychol.cam.ac.uk">[sdmlab.psychol.cam.ac.uk]</a><span class="citation-popover" role="note"><span class="citation-popover-source">sdmlab.psychol.cam.ac.uk</span><span class="citation-popover-snippet">Bad News Game &#124; Social Decision-Making LabThe Bad News Game is a multiple award-winning fake news intervention aimed at building psycholo...</span></span></span>

## Why transfer remains difficult

Although the evidence is stronger than many people assume, important limitations remain.

First, most studies measure transfer over weeks or months rather than years. Long-term maintenance probably requires repeated use, refresher training or continued application.

Second, improvements are rarely complete. Participants still display biases after training; they simply do so less often or less strongly. Debiasing reduces vulnerability rather than producing perfectly rational judgement.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://journals.sagepub.com/doi/abs/10.1177/2372732215600886" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: journals.sagepub.com">[Sage Journals]</a><span class="citation-popover" role="note"><span class="citation-popover-source">journals.sagepub.com</span><span class="citation-popover-snippet">Sage JournalsImproved Decision Making With a Single Training...by CK Morewedge · 2015 · Cited by 589 — Participants received a single tr...</span></span></span>

Third, many interventions target specific families of biases. A programme that improves resistance to confirmation bias does not necessarily reduce every other cognitive bias. Researchers increasingly distinguish between teaching a small number of broadly useful reasoning habits—such as actively searching for contradictory evidence—and attempting to eliminate an extensive catalogue of biases.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://journals.sagepub.com/doi/abs/10.1177/2372732215600886" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: journals.sagepub.com">[Sage Journals]</a><span class="citation-popover" role="note"><span class="citation-popover-source">journals.sagepub.com</span><span class="citation-popover-snippet">Sage JournalsImproved Decision Making With a Single Training...by CK Morewedge · 2015 · Cited by 589 — Participants received a single tr...</span></span></span>

Finally, real-world decisions involve competing pressures that laboratory studies cannot fully reproduce. Time constraints, organisational incentives, emotional investment and group dynamics all encourage biased reasoning. Training can improve individual judgement, but it does not remove structural sources of poor decisions. Even the developers of successful interventions argue that training should complement better decision processes rather than replace them.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://clsbe.lisboa.ucp.pt/system/files/assets/files/2016-paper-carey-morewedge.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: clsbe.lisboa.ucp.pt">[Católica-Lisbon SBE]</a><span class="citation-popover" role="note"><span class="citation-popover-source">clsbe.lisboa.ucp.pt</span><span class="citation-popover-title">2016 paper carey morewedge</span><span class="citation-popover-snippet">Católica-Lisbon SBEDebiasing DecisionsSeptember 11, 2015 — by CK Morewedge · 2015 · Cited by 591 — underlying structural causes of biased...</span><span class="citation-popover-meta">Published: September 11, 2015</span></span></span>

## What the evidence means for improving analytical thinking

The strongest debiasing interventions do not rely on raising awareness alone. Instead, they repeatedly place learners into situations where biased reasoning feels natural, provide immediate feedback, explain the underlying mistake and require another attempt under slightly different conditions.

The studies showing the clearest transfer also avoid obvious classroom cues. Learners are later confronted with unfamiliar cases where no one announces which bias is relevant, making success depend on recognising the underlying reasoning problem for themselves. That makes these findings particularly relevant to analytical thinking in everyday life, where mistakes rarely arrive with helpful labels.

Current evidence therefore supports a measured conclusion. Short games and videos can improve judgement beyond their original teaching examples, especially when they include active practice and personalised feedback.   }
  function localeMatches() {
    var languages = [];
    var exactMarket = '';
    var languageMarket = '';
    try {
      if (navigator.languages && navigator.languages.length) languages = Array.prototype.slice.call(navigator.languages);
      else if (navigator.language) languages = [navigator.language];
    } catch (err) {}
    for (var i = 0; i< languages.length; i += 1) {
      var normalized = normalize(languages[i]);
      if (!normalized) continue;
      if (localeMarketMap[normalized]) {
        exactMarket = localeMarketMap[normalized];
        break;
      }
      var languageOnly = normalized.split('-')[0];
      if (!languageMarket && localeMarketMap[languageOnly]) languageMarket = localeMarketMap[languageOnly];
    }
    return { exact: exactMarket, language: languageMarket };
  }
  function inferFromLocale() {
    var matches = localeMatches();
    return matches.exact || matches.language || '';
  }
  function inferFromTimezone() {
    var tz = '';
    try { tz = String(Intl.DateTimeFormat().resolvedOptions().timeZone || ''); } catch (err) {}
    if (!tz) return '';
    for (var i = 0; i< timezoneRules.length; i += 1) {
      var rule = timezoneRules[i] || {};
      try {
        if (new RegExp(rule.pattern).test(tz)) return rule.market;
      } catch (err) {}
    }
    return '';
  }
  function inferMarket(available, options) {
    available = Array.isArray(available) ? available : [];
    options = options || {};
    var storageKey = options.storageKey || 'phoenix-affiliate-market';
    try {
      var saved = window.localStorage && localStorage.getItem(storageKey);
      if (saved && available.indexOf(saved) >= 0) return saved;
    } catch (err) {}
    var timezoneMarket = inferFromTimezone();
    if (timezoneMarket && available.indexOf(timezoneMarket) >= 0) return timezoneMarket;
    var localeMarkets = localeMatches();
    if (localeMarkets.exact && available.indexOf(localeMarkets.exact) >= 0) return localeMarkets.exact;
    if (localeMarkets.language && available.indexOf(localeMarkets.language) >= 0) return localeMarkets.language;
    if (options.defaultMarket && available.indexOf(options.defaultMarket) >= 0) return options.defaultMarket;
    return available[0] || '';
  }
  window.PhoenixAffiliateLocation = {
    normalize: normalize,
    inferMarket: inferMarket,
    inferFromLocale: inferFromLocale,
    inferFromTimezone: inferFromTimezone
  };
