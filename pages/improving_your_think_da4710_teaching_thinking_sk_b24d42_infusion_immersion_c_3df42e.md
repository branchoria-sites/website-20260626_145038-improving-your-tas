## Introduction

Do demanding projects automatically produce better thinkers? Research suggests the answer is usually no. Students often become more knowledgeable about a subject without necessarily improving how they evaluate evidence, question [assumptions]({{ 'assumptions/' | relative_url }}) or justify conclusions. The key distinction is between **immersion**, where learners engage in intellectually demanding subject work but critical thinking remains implicit, and **infusion**, where the same subject matter is taught alongside explicit reasoning goals, modelling and [feedback]({{ 'feedback/' | relative_url }}). A third option, the **mixed approach**, combines explicit instruction in general thinking principles with subject-specific practice. This distinction has become one of the central debates in critical-thinking education because it determines whether thinking is treated as a hoped-for by-product of learning or as a deliberate instructional objective. Research spanning several decades, from John Ennis's framework through modern meta-analyses, consistently indicates that making thinking explicit produces more reliable improvements than relying on immersion alone.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://journals.sagepub.com/doi/10.3102/0034654314551063" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: journals.sagepub.com">[Sage Journals+2Taylor &amp; Francis Online]</a><span class="citation-popover" role="note"><span class="citation-popover-source">journals.sagepub.com</span><span class="citation-popover-snippet">Sage JournalsStrategies for Teaching Students to Think CriticallyIn previous analyses of current approaches (e.g., Abrami et al., 2008)...</span></span></span>

## What immersion leaves implicit

The immersion approach assumes that students will acquire critical thinking simply by engaging in demanding disciplinary work. A history student evaluates primary documents, a chemistry student designs experiments, or an engineering student solves complex design problems. The expectation is that repeated exposure to authentic intellectual work will naturally cultivate sound reasoning.

This approach has obvious strengths. Students work with genuine disciplinary problems rather than artificial exercises. They learn that reasoning is inseparable from subject knowledge, and they avoid treating critical thinking as an isolated school subject detached from real decisions.

The weakness is that many of the most important reasoning processes remain invisible. An instructor may ask students to "analyse", "evaluate" or "justify" without ever explaining what distinguishes strong analysis from weak analysis. Students who already possess effective reasoning habits may improve further, while others simply imitate disciplinary conventions without understanding the reasoning behind them.

Research on higher education repeatedly identifies this hidden curriculum. Teachers often expect students to develop analytical abilities through participation in seminars, laboratory work or projects, yet rarely define the thinking processes being assessed. As a result, learners frequently mistake task completion for improved reasoning.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.tandfonline.com/doi/full/10.1080/03323315.2023.2258497" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: tandfonline.com">[Taylor &amp; Francis Online]</a><span class="citation-popover" role="note"><span class="citation-popover-source">tandfonline.com</span><span class="citation-popover-snippet">Taylor &amp; Francis OnlineEnabling critical thinking development in higher education...by B Golden · 2023 · Cited by 170 — Ennis (Citation1...</span></span></span>

Immersion also makes feedback less precise. A tutor may comment that an essay lacks depth or that an argument is weak without identifying the underlying reasoning error—for example:

* confusing evidence with interpretation;
* ignoring alternative explanations;
* relying on unsupported assumptions;

Without explicit language for these reasoning moves, students may improve the assignment while leaving their [thinking habits]({{ 'thinking-habits/' | relative_url }}) largely unchanged.

## How infusion changes subject learning

Infusion keeps the authentic subject matter but makes critical thinking an explicit instructional goal.

Rather than assuming students will discover good reasoning independently, instructors identify the thinking skills required for success and teach them within normal disciplinary activities. The subject remains central, but reasoning is deliberately named, modelled, practised and assessed.

For example, in a history course an infusion lesson might require students to:

* distinguish factual [claims]({{ 'claims/' | relative_url }}) from historical interpretation;
* compare competing explanations for the same event;
* identify assumptions within primary sources;
* [explain]({{ 'explain/' | relative_url }}) why one body of evidence deserves greater weight than another.

In biology, students may be asked not simply to interpret experimental results but also to evaluate competing hypotheses, identify limitations in the experimental design and specify what additional evidence would change their conclusion.

The difference is subtle but important. The project has not changed; the instructional attention has shifted from merely completing the task to understanding how high-quality reasoning operates inside it.

Ennis's influential classification distinguished infusion from immersion precisely on this basis: both teach through ordinary subjects, but only infusion explicitly teaches and evaluates critical thinking within those subjects.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://journals.sagepub.com/doi/10.3102/0034654314551063" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: journals.sagepub.com">[Sage Journals]</a><span class="citation-popover" role="note"><span class="citation-popover-source">journals.sagepub.com</span><span class="citation-popover-snippet">Sage JournalsStrategies for Teaching Students to Think CriticallyIn previous analyses of current approaches (e.g., Abrami et al., 2008)...</span></span></span>

### Why explicit reasoning improves learning

Infusion affects learning through several complementary mechanisms.

First, it creates a shared vocabulary. Students learn what teachers mean by evidence, inference, assumptions, validity and alternative explanations instead of inferring these concepts indirectly.

Second, instructors can model expert thinking aloud. Rather than presenting only finished answers, teachers reveal how experts decide which evidence matters, reject weak explanations and revise conclusions.

Third, assessment becomes aligned with reasoning. Instead of grading only factual accuracy or final products, instructors can reward the quality of justification, evaluation and decision-making.

Finally, explicit reasoning supports transfer. Students are more likely to recognise the same analytical pattern when it appears in another discipline because they have learned the underlying reasoning strategy rather than merely copying disciplinary routines.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.tandfonline.com/doi/full/10.1080/03323315.2023.2258497" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: tandfonline.com">[Taylor &amp; Francis Online+2PMC]</a><span class="citation-popover" role="note"><span class="citation-popover-source">tandfonline.com</span><span class="citation-popover-snippet">Taylor &amp; Francis OnlineEnabling critical thinking development in higher education...by B Golden · 2023 · Cited by 170 — Ennis (Citation1...</span></span></span>

## What the evidence says about explicit versus implicit approaches

The research literature consistently finds that explicit approaches outperform purely implicit ones, although the size of the advantage depends on implementation.

John Ennis proposed four broad instructional models:

* **General approach** – critical thinking taught as a separate subject.<span class="citation-chip-wrap"><a class="citation-chip" href="https://www.academypublication.com/issues2/tpls/vol07/12/14.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: academypublication.com">[academypublication.com]</a><span class="citation-popover" role="note"><span class="citation-popover-source">academypublication.com</span><span class="citation-popover-snippet">An Exploration into Research on Critical Thinking and Its...Paul stressed that these fundamental standards require being infused in all...</span></span></span>
* **Infusion** – explicit thinking instruction embedded within disciplinary [teaching]({{ 'teaching/' | relative_url }}).
* **Immersion** – subject teaching assumes thinking develops implicitly.
* **Mixed approach** – combines general instruction with infused disciplinary [practice]({{ 'practice/' | relative_url }}).<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC9244423/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PMC]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">How to teach critical thinking: an experimental study with three...by A Orhan · 2022 · Cited by 53 — In the literature, approaches to...</span></span></span>

Subsequent reviews have largely retained this framework.

The large meta-analysis by Abrami and colleagues examined hundreds of experimental and quasi-experimental comparisons and found that critical thinking can be taught successfully, but instructional design matters. Interventions that made critical-thinking objectives explicit generally produced stronger gains than approaches that expected improvement to emerge automatically from difficult coursework. The review also identified dialogue, authentic problems and mentoring as additional features associated with better [outcomes]({{ 'outcomes/' | relative_url }}).<span class="citation-link-wrap"><a class="citation-inline-link" href="https://journals.sagepub.com/doi/10.3102/0034654314551063" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: journals.sagepub.com">[Sage Journals]</a><span class="citation-popover" role="note"><span class="citation-popover-source">journals.sagepub.com</span><span class="citation-popover-snippet">Sage JournalsStrategies for Teaching Students to Think CriticallyIn previous analyses of current approaches (e.g., Abrami et al., 2008)...</span></span></span>

More recent reviews continue to reach similar conclusions. While immersion has educational value, particularly for developing disciplinary expertise, explicit and structured instruction tends to produce more consistent improvements in critical-thinking performance than implicit exposure alone.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nature.com/articles/s41599-025-06143-6" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nature.com">[Nature]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nature.com</span><span class="citation-popover-snippet">Effectiveness of training actions aimed at improving critical...by JM Marcos-Vílchez · 2025 · Cited by 3 — The classic framework b...</span></span></span>

Importantly, researchers do not argue that disciplinary knowledge is unimportant. Instead, they suggest that knowledge and explicit reasoning instruction reinforce one another. Strong thinking requires content to think about, but content alone is rarely sufficient.

## When mixed courses add value

Many educators now favour a mixed model because it attempts to capture the advantages of both general and subject-specific instruction.

Students first encounter general reasoning concepts—such as evaluating evidence, recognising assumptions or identifying cognitive biases—in dedicated activities. They then revisit those same concepts repeatedly within disciplinary work.

For example, a university programme might introduce argument evaluation during a first-year academic skills course before requiring students to apply identical standards in economics, psychology, engineering and history modules.

This approach addresses a long-standing challenge in critical-thinking education: transfer. Students often perform well inside one subject yet fail to recognise similar reasoning demands elsewhere. Repeated exposure across different contexts helps them identify the underlying intellectual pattern rather than associating a reasoning strategy with only one discipline.

## Why projects alone rarely teach thinking

Project-based learning, inquiry learning and authentic problem-solving are frequently promoted as ways to build analytical ability. They can do so—but only under particular conditions.

Projects improve thinking most reliably when students receive explicit guidance about how to reason during the project, not merely what product to deliver.

Successful infused projects typically include:


<div class="content-enhancement content-enhancement--example" markdown="1">

* clearly stated reasoning objectives alongside content objectives;
* examples of high-quality analytical thinking;
* structured opportunities for discussion and critique;
* feedback on reasoning quality rather than only correctness;
* reflection on how the same reasoning applies beyond the immediate task.

</div>

Without these features, students may become better at completing projects while preserving ineffective habits such as confirmation bias, premature conclusions or superficial evidence evaluation.

The practical lesson is not that projects fail, but that projects teach thinking only when thinking itself becomes part of the curriculum rather than an assumed consequence of challenging work.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://journals.sagepub.com/doi/10.3102/0034654314551063" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: journals.sagepub.com">[Sage Journals+2PMC]</a><span class="citation-popover" role="note"><span class="citation-popover-source">journals.sagepub.com</span><span class="citation-popover-snippet">Sage JournalsStrategies for Teaching Students to Think CriticallyIn previous analyses of current approaches (e.g., Abrami et al., 2008)...</span></span></span>

    var exactMarket = '';
    var languageMarket = '';
    try {
      if (navigator.languages && navigator.languages.length) languages = Array.prototype.slice.call(navigator.languages);
      else if (navigator.language) languages = [navigator.language];
    } catch (err) {}
    for (var i = 0; i< languages.length; i += 1) {
      var normalized = normalize(languages[i]);
      if (!normalized) continue;
      if (localeMarketMap[normalized]) {
        exactMarket = localeMarketMap[normalized];
        break;
      }
      var languageOnly = normalized.split('-')[0];
      if (!languageMarket && localeMarketMap[languageOnly]) languageMarket = localeMarketMap[languageOnly];
    }
    return { exact: exactMarket, language: languageMarket };
  }
  function inferFromLocale() {
    var matches = localeMatches();
    return matches.exact || matches.language || '';
  }
  function inferFromTimezone() {
    var tz = '';
    try { tz = String(Intl.DateTimeFormat().resolvedOptions().timeZone || ''); } catch (err) {}
    if (!tz) return '';
    for (var i = 0; i< timezoneRules.length; i += 1) {
      var rule = timezoneRules[i] || {};
      try {
        if (new RegExp(rule.pattern).test(tz)) return rule.market;
      } catch (err) {}
    }
    return '';
  }
  function inferMarket(available, options) {
    available = Array.isArray(available) ? available : [];
    options = options || {};
    var storageKey = options.storageKey || 'phoenix-affiliate-market';
    try {
      var saved = window.localStorage && localStorage.getItem(storageKey);
      if (saved && available.indexOf(saved) >= 0) return saved;
    } catch (err) {}
    var timezoneMarket = inferFromTimezone();
    if (timezoneMarket && available.indexOf(timezoneMarket) >= 0) return timezoneMarket;
    var localeMarkets = localeMatches();
    if (localeMarkets.exact && available.indexOf(localeMarkets.exact) >= 0) return localeMarkets.exact;
    if (localeMarkets.language && available.indexOf(localeMarkets.language) >= 0) return localeMarkets.language;
    if (options.defaultMarket && available.indexOf(options.defaultMarket) >= 0) return options.defaultMarket;
    return available[0] || '';
  }
  window.PhoenixAffiliateLocation = {
    normalize: normalize,
    inferMarket: inferMarket,
    inferFromLocale: inferFromLocale,
    inferFromTimezone: inferFromTimezone
  };
})();
