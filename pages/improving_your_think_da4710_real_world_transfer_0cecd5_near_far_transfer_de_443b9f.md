## Introduction

The value of a thinking skill is measured not by how well you use it in [practice]({{ 'practice/' | relative_url }}) exercises, but by whether it appears when you face a real decision. This ability to carry a skill from one situation to another is known as **transfer**. The easiest form is **near transfer**, where the new task closely resembles the one you practised. The harder form is **far transfer**, where the surface details are different but the same underlying principle still applies. More than a century of research suggests that near transfer is common, while far transfer is much less reliable unless people deliberately learn to recognise deeper patterns rather than familiar examples.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://jaymctighe.com/wp-content/uploads/2011/04/Transfer-of-Learning-Perkins-and-Salomon.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: jaymctighe.com">[Jay McTighe+2Structural Learning]</a><span class="citation-popover" role="note"><span class="citation-popover-source">jaymctighe.com</span><span class="citation-popover-snippet">Jay McTigheTransfer of Learning by Perkins and SalomonNear transfer refers to transfer between very similar contexts, as for instance whe...</span></span></span>

For improving analytical thinking, this distinction matters because everyday decisions rarely announce which reasoning tool you should use. Buying insurance, judging a health claim, evaluating a workplace proposal and deciding whether to trust a striking statistic may all require the same habits of evidence-based thinking, even though they look unrelated at first glance.

## Near transfer in similar tasks

Near transfer occurs when two situations share obvious features. The learner recognises the new problem because it resembles one already solved.

In everyday life, near transfer often feels effortless because the visible cues are familiar:

* Using the same budgeting spreadsheet for this month's household expenses as last month's.
* Applying a checklist for proofreading one report to another report in the same format.
* Spotting misleading percentages in a second newspaper article after analysing a similar one earlier in the week.
* Using the same framework for comparing two [job offers]({{ 'job-offers/' | relative_url }}) after previously comparing university courses.

The classic explanation dates back to the work of Edward Thorndike and Robert Woodworth in the early twentieth century. They argued that transfer depends on the degree to which two situations share **common elements**, rather than on the existence of a general mental faculty that automatically improves reasoning everywhere. Their idea challenged the older belief that studying demanding subjects alone would naturally strengthen thinking across all areas of life.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.structural-learning.com/post/transfer-learning-complete-guide-teachers" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: structural-learning.com">[Structural Learning]</a><span class="citation-popover" role="note"><span class="citation-popover-source">structural-learning.com</span><span class="citation-popover-snippet">Structural LearningTransfer of Learning: A Complete Guide5 days ago — Near transfer happens more naturally, while far transfer requires e...</span></span></span>

David Perkins and Gavriel Salomon later described much near transfer as **low-road transfer**. After enough practice, familiar cues trigger well-learned routines with little conscious effort. A pilot's pre-flight checklist, a nurse's medication verification routine or an accountant's reconciliation process are examples where repeated exposure encourages automatic [application]({{ 'application/' | relative_url }}) in similar situations.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://jaymctighe.com/wp-content/uploads/2011/04/Transfer-of-Learning-Perkins-and-Salomon.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: jaymctighe.com">[Jay McTighe]</a><span class="citation-popover" role="note"><span class="citation-popover-source">jaymctighe.com</span><span class="citation-popover-snippet">Jay McTigheTransfer of Learning by Perkins and SalomonNear transfer refers to transfer between very similar contexts, as for instance whe...</span></span></span>

This automaticity is valuable because it reduces mental effort for routine decisions. However, it also creates a limitation: if the appearance of the problem changes substantially, the routine may never be activated.

## Far transfer across unfamiliar settings

Far transfer asks a more demanding question: can you recognise that two very different situations share the same logical structure?

Instead of repeating a familiar procedure, you must ignore distracting surface differences and identify the underlying principle.

For example:

* Someone who understands experimental controls in science may apply the same reasoning when assessing whether a company's new sales strategy really caused higher revenue.
* A person who has learned to distinguish correlation from [causation]({{ 'causation/' | relative_url }}) in psychology may recognise the same mistake in financial commentary or social media discussions.
* A habit of comparing competing explanations while reading history may later improve decisions about workplace problems, where several causes could [explain]({{ 'explain/' | relative_url }}) declining performance.

These examples require abstraction. The learner must mentally translate one domain into another before applying the reasoning strategy.

Research consistently finds this kind of transfer much harder than educators once hoped. Reviews of cognitive training and "brain training" programmes repeatedly conclude that while people generally improve at tasks very similar to those they practise, convincing evidence for broad far transfer into unrelated skills is limited. Improvements often remain close to the original training unless the new task shares important structural features.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nifdi.org/resources/88-news/kerry-hempenstall/758-near-and-far-transfer-in-cognitive-training.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nifdi.org">[nifdi.org+2Structural Learning]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nifdi.org</span><span class="citation-popover-snippet">Near and far transfer in cognitive trainingNear transfer occurs when skills learned in one context are applied to similar contexts, while...</span></span></span>

This does not mean far transfer is impossible. Rather, it appears to depend on more than repeated exposure. Learners usually need to identify general principles, compare examples across contexts and consciously search for situations where those principles apply.

## Why far transfer so often fails

Many thinking skills appear portable in theory but remain tied to the circumstances in which they were learned.

Several mechanisms explain this gap.

**Surface features dominate attention.** People naturally notice obvious similarities before deeper relationships. A medical study and a business experiment look different even if both require the same logic of comparison.

**Context provides hidden prompts.** During training, learners are told what topic they are studying. Outside training, nobody labels a conversation as an exercise in confirmation bias or probabilistic reasoning.

**Knowledge and reasoning interact.** Analytical habits depend on having enough background knowledge to recognise when a principle is relevant. Without understanding how scientific evidence, financial statements or legal arguments normally work, even excellent reasoning strategies may not activate appropriately.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.researchgate.net/publication/2402396_Transfer_Of_Learning" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: researchgate.net">[ResearchGate]</a><span class="citation-popover" role="note"><span class="citation-popover-source">researchgate.net</span><span class="citation-popover-snippet">ResearchGate(PDF) Transfer Of LearningTransfer includes near transfer (to closely related contexts and performances) and far transfer (to...</span></span></span>

**Time [pressure]({{ 'pressure/' | relative_url }}) encourages familiar routines.** Everyday decisions often reward speed rather than careful abstraction. Under deadlines, people default to previously successful habits instead of searching for deeper analogies.

The result is that someone may genuinely understand a reasoning principle in one setting while failing to notice that it applies elsewhere.

## How to practise the bridge between them

Fortunately, research suggests that transfer can be strengthened when learning is designed specifically to encourage it rather than assuming it will emerge automatically.

### Compare different examples that share one principle

Instead of practising only one type of problem, deliberately study several situations that rely on the same reasoning.

For example, examine:


<div class="content-enhancement content-enhancement--comparison" markdown="1">

* a medical headline,
* an investment advertisement,
* a workplace performance dashboard, and
* a sports statistic,

</div>

all through the question: *Does this evidence justify the conclusion?*

The changing contexts encourage attention to the underlying reasoning rather than the surface story.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://jaymctighe.com/wp-content/uploads/2011/04/Transfer-of-Learning-Perkins-and-Salomon.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: jaymctighe.com">[Jay McTighe]</a><span class="citation-popover" role="note"><span class="citation-popover-source">jaymctighe.com</span><span class="citation-popover-snippet">Jay McTigheTransfer of Learning by Perkins and SalomonNear transfer refers to transfer between very similar contexts, as for instance whe...</span></span></span>

### Name the principle, not just the example

Rather than remembering, "This article confused correlation with causation," state the more general lesson:

> "Whenever two events occur together, I should ask whether another explanation could account for both."

General statements travel more easily across domains than memories tied to one specific case.

### Look backwards from new decisions

Perkins and Salomon describe **high-road transfer** as deliberately searching memory for relevant ideas when facing a new situation. Instead of asking, "Have I seen this exact problem before?", ask:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* What does this situation remind me of?
* Have I encountered a similar pattern elsewhere?
* Which reasoning strategy worked then?

</div>

This conscious search helps build bridges between apparently unrelated experiences.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://jaymctighe.com/wp-content/uploads/2011/04/Transfer-of-Learning-Perkins-and-Salomon.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: jaymctighe.com">[Jay McTighe]</a><span class="citation-popover" role="note"><span class="citation-popover-source">jaymctighe.com</span><span class="citation-popover-snippet">Jay McTigheTransfer of Learning by Perkins and SalomonNear transfer refers to transfer between very similar contexts, as for instance whe...</span></span></span>

### Practise under realistic conditions

Transfer improves when practice resembles the uncertainty of everyday decisions.

Rather than always analysing neatly prepared textbook cases, include situations with incomplete information, conflicting evidence and ambiguous conclusions. These conditions more closely resemble workplace, financial and personal decisions, where recognising the relevant thinking skill is itself part of the challenge.

## Historical perspective: from general mental training to specific transfer

Ideas about transfer have changed substantially over the past century.

Early educational traditions often assumed that studying demanding subjects automatically strengthened general reasoning. Mathematics, classical languages and formal logic were believed to improve the mind broadly.

Thorndike and Woodworth's research challenged this assumption by arguing that transfer depends on shared elements between learning and application rather than on universal mental strengthening. Later work by Perkins and Salomon refined the picture further by distinguishing automatic low-road transfer from deliberate high-road transfer, recognising that broad transfer is possible but usually requires conscious abstraction rather than passive exposure.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://en.wikipedia.org/wiki/Transfer_of_learning" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: Wikipedia">[Wikipedia+2Jay McTighe]</a><span class="citation-popover" role="note"><span class="citation-popover-source">Wikipedia</span><span class="citation-popover-title">Transfer of learning</span><span class="citation-popover-snippet">Transfer of learning</span></span></span>

Modern evidence broadly supports this more cautious position. Near transfer is routinely observed, whereas far transfer demands careful instructional design, varied practice and active reflection rather than simply increasing the amount of practice on one task.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nifdi.org/resources/88-news/kerry-hempenstall/758-near-and-far-transfer-in-cognitive-training.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nifdi.org">[nifdi.org+2Lirias]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nifdi.org</span><span class="citation-popover-snippet">Near and far transfer in cognitive trainingNear transfer occurs when skills learned in one context are applied to similar contexts, while...</span></span></span>

## What this means for everyday decisions

The practical lesson is not that thinking skills are trapped within individual domains, but that they rarely travel by themselves.

Near transfer lets familiar routines become efficient habits, making recurring decisions faster and more reliable. Far transfer requires recognising that very different situations share the same structure, then deliberately adapting a principle instead of repeating a procedure.

People who consistently improve their analytical thinking tend to build this bridge intentionally. They practise identifying common patterns across different contexts, give names to the principles behind successful decisions and regularly ask where else those principles might apply. Over time, the distance between "similar" and "different" situations begins to shrink, making transfer more likely whenever a genuinely new decision appears.

      if (navigator.languages && navigator.languages.length) languages = Array.prototype.slice.call(navigator.languages);
      else if (navigator.language) languages = [navigator.language];
    } catch (err) {}
    for (var i = 0; i< languages.length; i += 1) {
      var normalized = normalize(languages[i]);
      if (!normalized) continue;
      if (localeMarketMap[normalized]) {
        exactMarket = localeMarketMap[normalized];
        break;
      }
      var languageOnly = normalized.split('-')[0];
      if (!languageMarket && localeMarketMap[languageOnly]) languageMarket = localeMarketMap[languageOnly];
    }
    return { exact: exactMarket, language: languageMarket };
  }
  function inferFromLocale() {
    var matches = localeMatches();
    return matches.exact || matches.language || '';
  }
  function inferFromTimezone() {
    var tz = '';
    try { tz = String(Intl.DateTimeFormat().resolvedOptions().timeZone || ''); } catch (err) {}
    if (!tz) return '';
    for (var i = 0; i< timezoneRules.length; i += 1) {
      var rule = timezoneRules[i] || {};
      try {
        if (new RegExp(rule.pattern).test(tz)) return rule.market;
      } catch (err) {}
    }
    return '';
  }
  function inferMarket(available, options) {
    available = Array.isArray(available) ? available : [];
    options = options || {};
    var storageKey = options.storageKey || 'phoenix-affiliate-market';
    try {
      var saved = window.localStorage && localStorage.getItem(storageKey);
      if (saved && available.indexOf(saved) >= 0) return saved;
    } catch (err) {}
    var timezoneMarket = inferFromTimezone();
    if (timezoneMarket && available.indexOf(timezoneMarket) >= 0) return timezoneMarket;
    var localeMarkets = localeMatches();
    if (localeMarkets.exact && available.indexOf(localeMarkets.exact) >= 0) return localeMarkets.exact;
    if (localeMarkets.language && available.indexOf(localeMarkets.language) >= 0) return localeMarkets.language;
    if (options.defaultMarket && available.indexOf(options.defaultMarket) >= 0) return options.defaultMarket;
    return available[0] || '';
  }
  window.PhoenixAffiliateLocation = {
    normalize: normalize,
    inferMarket: inferMarket,
    inferFromLocale: inferFromLocale,
    inferFromTimezone: inferFromTimezone
  };
