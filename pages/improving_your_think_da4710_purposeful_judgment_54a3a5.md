## Introduction

Critical thinking is best understood as purposeful, self-regulated judgement: the deliberate process of deciding what to believe or what to do by interpreting information, analysing reasons, evaluating evidence, drawing inferences, and explaining how the conclusion was reached. That matters because it separates critical thinking from two common impostors: reflexive [cynicism]({{ 'cynicism/' | relative_url }}) and clever opinion-making. A critical thinker is not simply someone who doubts everything, wins arguments, or spots flaws quickly. The stronger habit is more disciplined: asking what question is being answered, what evidence is available, what [assumptions]({{ 'assumptions/' | relative_url }}) are being made, what alternatives remain plausible, and how confident the conclusion should be. The influential Delphi Report defined critical thinking in exactly this decision-focused way, as “purposeful, self-regulatory judgment” directed towards deciding “what to believe or what to do”.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://insightassessment.com/iaresource/the-delphi-report-a-statement-of-expert-consensus-on-the-definition-of-critical-thinking/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: insightassessment.com">[Insight Assessment]</a><span class="citation-popover" role="note"><span class="citation-popover-source">insightassessment.com</span><span class="citation-popover-title">Insight Assessment The Delphi Report</span><span class="citation-popover-snippet">Insight AssessmentThe Delphi Report - Insight Assessment...</span></span></span>

Within [improving your thinking and analytical skills]({{ 'improving-your-thinking-and-analytical/' | relative_url }}), this definition is useful because it makes better thinking visible. It turns “be more critical” into a route: clarify the issue, test the support, compare interpretations, and show why the answer follows. It also makes critical thinking a [practice]({{ 'practice/' | relative_url }}) rather than a personality trait. People improve not by becoming permanently suspicious, but by learning when to slow down, how to handle evidence, and how to revise a judgement without treating revision as defeat.

## Why judgement, not cynicism, is the centre

The word “critical” often sounds negative in ordinary speech, as though a critical person is mainly fault-finding. In the critical-thinking tradition, however, the root idea is closer to discernment: making reliable judgements from reliable information. Monash University’s student guidance puts the point plainly: applying critical thinking does not mean being negative or focusing on faults; it means clarifying your thinking so that you can break down information, interpret it, and arrive at an informed decision or judgement.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.monash.edu/student-academic-success/sharpen-your-thinking/critical-thinking/what-is-critical-thinking" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: monash.edu">[Monash University]</a><span class="citation-popover" role="note"><span class="citation-popover-source">monash.edu</span><span class="citation-popover-title">University What is critical thinking?</span><span class="citation-popover-snippet">Monash UniversityWhat is critical thinking? - Student Academic Success...</span></span></span>

This distinction is not cosmetic. Cynicism begins with distrust and often ends there. Purposeful judgement begins with a question and moves towards a justified answer. A cynical reader of a health claim, for example, might say, “They are probably lying.” A credulous reader might say, “It sounds scientific, so it is probably true.” A critical thinker asks something more useful: What exactly is being claimed? What kind of evidence would support it? Is the evidence from a controlled study, a personal anecdote, a marketing page, or an expert body? Are there conflicts of interest? How strong should my conclusion be?

That is why critical thinking is not the opposite of trust. It is the discipline of proportioning trust to reasons. Sometimes the critical judgement is “this claim is weak”. Sometimes it is “this claim is well supported”. Sometimes it is “the evidence is incomplete, so the responsible answer is provisional”. The outcome is not always rejection; it may be acceptance, suspension of judgement, a narrower conclusion, or a decision to seek better evidence.

Historically, this emphasis on judgement links modern critical-thinking theory to John Dewey’s older idea of reflective thinking. Dewey described reflective thinking as active, persistent and careful consideration of a belief in light of the grounds supporting it and the further conclusions to which it tends. The Stanford Encyclopedia of Philosophy traces critical thinking as an educational goal through Dewey, later assessment work, Bloom’s taxonomy, and Robert Ennis’s influential definition of critical thinking as reasonable reflective thinking focused on deciding what to believe or do.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://plato.stanford.edu/entries/critical-thinking/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: plato.stanford.edu">[Stanford Encyclopedia of Philosophy]</a><span class="citation-popover" role="note"><span class="citation-popover-source">plato.stanford.edu</span><span class="citation-popover-title">Encyclopedia of Philosophy</span><span class="citation-popover-snippet">Critical Thinking (Stanford Encyclopedia of Philosophy)...</span></span></span>

The historical pattern is revealing. Critical thinking did not develop mainly as a technique for sounding sceptical. It developed as an educational ideal for judgement under uncertainty: how to think carefully enough that belief and action are answerable to reasons.

## The mechanism: deciding what to believe or do

The phrase “purposeful, self-regulatory judgement” contains three important claims.

First, critical thinking is **purposeful**. It is directed at a task: understanding a text, judging a policy proposal, diagnosing a problem, deciding whether to trust a source, choosing between options, or explaining a conclusion. Without a purpose, “thinking critically” can become endless commentary. With a purpose, it has a standard of success: did the reasoning help answer the question?

Second, it is **judgement**. Critical thinking does not stop at collecting information. It weighs, compares, and decides. That does not mean rushing to certainty. A good judgement may be tentative, conditional, or limited: “The evidence points this way, but only for this population”; “This explanation is more plausible than the alternatives”; “This is not yet knowable from the available data.” The Delphi Report’s definition connects judgement to interpretation, analysis, evaluation, inference, and explanation, which means the conclusion should be traceable to the work done along the way.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://insightassessment.com/iaresource/the-delphi-report-a-statement-of-expert-consensus-on-the-definition-of-critical-thinking/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: insightassessment.com">[Insight Assessment]</a><span class="citation-popover" role="note"><span class="citation-popover-source">insightassessment.com</span><span class="citation-popover-title">Insight Assessment The Delphi Report</span><span class="citation-popover-snippet">Insight AssessmentThe Delphi Report - Insight Assessment...</span></span></span>

Third, it is **self-regulatory**. The thinker monitors the process rather than merely applying intelligence outward. [Self-regulation]({{ 'self-regulation/' | relative_url }}) asks: Am I interpreting the claim fairly? Have I ignored evidence because it is inconvenient? Am I using a double standard? Is my confidence stronger than the evidence? The Stanford Encyclopedia of Philosophy notes that critical thinkers have both abilities and dispositions that lead them to think critically when appropriate, and that the educational goal is not just a one-sentence definition but adoption of criteria and standards for careful thinking.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://plato.stanford.edu/entries/critical-thinking/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: plato.stanford.edu">[Stanford Encyclopedia of Philosophy]</a><span class="citation-popover" role="note"><span class="citation-popover-source">plato.stanford.edu</span><span class="citation-popover-title">Encyclopedia of Philosophy</span><span class="citation-popover-snippet">Critical Thinking (Stanford Encyclopedia of Philosophy)...</span></span></span>

A practical example makes the mechanism clearer. Suppose a manager hears that remote workers are “less productive”. A non-critical response might accept or reject the claim based on preference. Purposeful judgement would separate the issue into parts:


<div class="content-enhancement content-enhancement--decision" markdown="1">

* What does “productive” mean here: output, availability, quality, collaboration, speed, profit, customer satisfaction?
* What comparison is being made: the same workers before and after remote work, different teams, or industry averages?
* What evidence is available: measured outcomes, impressions, surveillance metrics, missed deadlines, or isolated complaints?
* What alternative explanations exist: unclear goals, poor management, weak tools, meeting overload, selection effects?
* What decision follows: change policy, improve measurement, run a trial, or withhold judgement?

</div>

The point is not to make the issue complicated for its own sake. It is to prevent the conclusion from arriving before the reasoning.

## Skills and dispositions must work together

Critical thinking has a skill side and a character side. The skill side includes clarifying meanings, identifying arguments, analysing assumptions, evaluating evidence, making inferences, and explaining conclusions. The disposition side is the willingness to use those skills when they are inconvenient, effortful, socially awkward, or personally threatening.

The Delphi Report’s expert consensus described the ideal critical thinker as inquisitive, well-informed, trustful of reason, open-minded, flexible, fair-minded in evaluation, honest about personal biases, prudent in judgement, willing to reconsider, clear about issues, orderly in complex matters, diligent in seeking relevant information, and persistent in seeking results as precise as the situation permits.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://insightassessment.com/iaresource/the-delphi-report-a-statement-of-expert-consensus-on-the-definition-of-critical-thinking/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: insightassessment.com">[Insight Assessment]</a><span class="citation-popover" role="note"><span class="citation-popover-source">insightassessment.com</span><span class="citation-popover-title">Insight Assessment The Delphi Report</span><span class="citation-popover-snippet">Insight AssessmentThe Delphi Report - Insight Assessment...</span></span></span>

This is why someone can be verbally sharp yet not especially critical in the deeper sense. A person may be good at finding weaknesses in opponents’ arguments while ignoring weaknesses in their own. They may know the names of fallacies but use them as weapons rather than checks on reasoning. They may demand rigorous evidence from views they dislike and accept thin evidence for views they already hold. Purposeful judgement requires intellectual fairness, not just intellectual agility.

Research on critical-thinking dispositions has tried to make this willingness more explicit. Work associated with the California Critical Thinking Disposition Inventory identified seven positive dispositions: truth-seeking, open-mindedness, analyticity, systematicity, critical-thinking self-confidence, inquisitiveness, and maturity of judgement. The same work describes negative counterparts such as intellectual dishonesty in the use of data, intolerance of opposing ideas, haphazard procedure, mistrust of reason, indifference to new findings, and simplistic judgement.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.insightassessment.com/var/ezflow_site/storage/pdf/J_Infrml_Ppr%2B_2000%2B-%2BDisp%2B%26%2BSkls.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: insightassessment.com">[Insight Assessment]</a><span class="citation-popover" role="note"><span class="citation-popover-source">insightassessment.com</span><span class="citation-popover-title">Insight Assessment Documents\CT&amp;Cap_Docs\J_Infrml_Ppr.PD F</span><span class="citation-popover-snippet">Insight Assessment Documents\CT&amp;Cap_Docs\J_Infrml_Ppr.PD F</span></span></span>

Those dispositions matter because the hard part of critical thinking is often not knowing the rule. It is applying the rule when it costs something. Truth-seeking matters when the best evidence undermines your first view. Open-mindedness matters when an opposing argument is stronger than expected. Systematicity matters when a problem is boring but consequential. Maturity of judgement matters when the evidence is mixed and the answer must remain qualified.

## Explaining the route to conclusions

One of the clearest signs of purposeful judgement is that the thinker can [explain]({{ 'explain/' | relative_url }}) the route from question to conclusion. This is more demanding than stating an answer. It means showing the relationship between claim, evidence, assumptions, method, context, and degree of confidence.

The Delphi Report includes “explanation” as part of critical thinking: a critical judgement should be able to state the evidential, conceptual, methodological, criteriological, or contextual considerations on which it is based.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://insightassessment.com/iaresource/the-delphi-report-a-statement-of-expert-consensus-on-the-definition-of-critical-thinking/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: insightassessment.com">[Insight Assessment]</a><span class="citation-popover" role="note"><span class="citation-popover-source">insightassessment.com</span><span class="citation-popover-title">Insight Assessment The Delphi Report</span><span class="citation-popover-snippet">Insight AssessmentThe Delphi Report - Insight Assessment...</span></span></span> In plain terms, this means a good thinker should be able to answer questions such as:


<div class="content-enhancement content-enhancement--comparison" markdown="1">

* What evidence supports this conclusion?
* What standard are you using to judge it?
* What assumption connects the evidence to the claim?
* What would count against your conclusion?
* Why is this conclusion stronger than the alternatives?
* How certain should we be?

</div>

This is where critical thinking becomes teachable and reviewable. If reasoning stays hidden, it is hard to improve. Once the route is visible, others can test it, and the thinker can test it too.

Argument mapping is one practical way to make the route visible. It represents claims, reasons, objections, and assumptions so that the structure of an argument can be inspected rather than merely felt. In a well-known paper on argument maps, Charles Twardy describes how mapping helped reveal a common confusion: students sometimes treated an explanation of facts as though it were evidence for the facts. By laying out the structure, the mistake became easier to see and correct.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://web-archive.southampton.ac.uk/cogprints.org/3008/1/reasonpaper.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: web-archive.southampton.ac.uk">[University of Southampton Web Archive]</a><span class="citation-popover" role="note"><span class="citation-popover-source">web-archive.southampton.ac.uk</span><span class="citation-popover-snippet">University of Southampton Web Archive</span></span></span>

That example captures the value of explanation. Critical thinking is not just asking “Do I agree?” It is asking “What role is this statement playing?” A statistic may be evidence. A theory may be an explanation. A value may be a criterion. A background assumption may be doing hidden work. Once these roles are separated, judgement improves because the thinker is no longer treating every sentence as the same kind of support.

## What purposeful judgement looks like in practice

Purposeful judgement can be used in everyday life without turning every decision into a formal essay. The mechanism is scalable: the more important, uncertain, costly, or contested the issue, the more explicit the reasoning should become.

For a low-stakes decision, critical thinking may be a quick pause: “What am I assuming?” For a high-stakes decision, it may require a structured comparison of evidence, alternatives, risks, and unknowns. The key is not slowness for its own sake, but appropriate control.

A useful everyday pattern is:

1. **Name the judgement.** Decide whether the task is to believe a claim, choose an action, explain a cause, evaluate a source, or compare options.
2. **Clarify the claim.** Replace vague language with specific terms. “This policy works” might mean it reduces costs, improves [outcomes]({{ 'outcomes/' | relative_url }}), or satisfies stakeholders.

<div class="content-enhancement content-enhancement--step-flow" markdown="1">

3. **Separate evidence from interpretation.** Identify what is observed, what is inferred, and what is assumed.
4. **Check the standard.** Ask what would count as good enough evidence for this type of claim.
5. **Consider alternatives.** Look for rival explanations, not just objections.
6. **State the confidence level.** Avoid pretending that every conclusion is certain or that uncertainty means knowing nothing.
7. **Review the route.** Explain why the conclusion follows, and what would change it.

</div>

This sequence is not a rigid formula. It is a way to prevent common failures: accepting claims because they are fluent, rejecting claims because they are unfamiliar, confusing confidence with evidence, or treating a first explanation as the only explanation.

Educational evidence supports the idea that critical thinking improves when learners practise these moves explicitly rather than merely being told to “think harder”. A 2015 meta-analysis in the Review of Educational Research, summarised by ERIC, reviewed 341 effect sizes from quasi-experimental and true-experimental studies using standardised critical-thinking outcomes. It found a positive overall effect and reported that dialogue, authentic or situated problems, examples, and mentoring were associated with gains in critical-thinking skills.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://eric.ed.gov/?id=EJ1061695" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: eric.ed.gov">[ERIC]</a><span class="citation-popover" role="note"><span class="citation-popover-source">eric.ed.gov</span><span class="citation-popover-snippet">EJ1061695 - Strategies for Teaching Students to Think Critically: A Meta-Analysis, Review of Educational Research, 2015-Jun...</span></span></span>

That finding fits the mechanism. Purposeful judgement is not strengthened mainly by memorising definitions. It grows when people reason about real problems, expose their reasoning to questions, receive feedback, and try again.

## The historical shift from formal logic to reflective judgement

A historical comparison helps explain why purposeful judgement became such an important definition. Earlier approaches to better thinking often emphasised logic, argument validity, or detecting faulty statements. Those remain valuable, but they do not cover the whole problem of judgement in real life. Many everyday decisions involve incomplete evidence, unclear definitions, disputed values, uncertain probabilities, and changing contexts.

The Stanford Encyclopedia of Philosophy notes that definitions of critical thinking are contested but can be understood as different conceptions of “careful thinking directed to a goal”. It also records controversies over whether critical thinking is generalisable across domains, whether theories and teaching methods contain bias, and how critical thinking relates to problem-solving, decision-making, and creative thinking.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://plato.stanford.edu/entries/critical-thinking/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: plato.stanford.edu">[Stanford Encyclopedia of Philosophy]</a><span class="citation-popover" role="note"><span class="citation-popover-source">plato.stanford.edu</span><span class="citation-popover-title">Encyclopedia of Philosophy</span><span class="citation-popover-snippet">Critical Thinking (Stanford Encyclopedia of Philosophy)...</span></span></span>

The purposeful-judgement model responds to that complexity by widening the focus. It does not abandon logic, but it treats logic as one part of a larger act of judgement. In practice, a person may need to interpret language, assess credibility, understand context, evaluate methods, notice uncertainty, and explain a conclusion in terms that others can inspect. This is why the Delphi definition includes evidential, conceptual, methodological, criteriological, and contextual considerations.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://insightassessment.com/iaresource/the-delphi-report-a-statement-of-expert-consensus-on-the-definition-of-critical-thinking/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: insightassessment.com">[Insight Assessment]</a><span class="citation-popover" role="note"><span class="citation-popover-source">insightassessment.com</span><span class="citation-popover-title">Insight Assessment The Delphi Report</span><span class="citation-popover-snippet">Insight AssessmentThe Delphi Report - Insight Assessment...</span></span></span>

The comparison also shows why “critical thinking” should not be reduced to generic cleverness. A person can reason well in one domain and poorly in another if they lack relevant background knowledge. A statistician may assess a poll better than a novice; a mechanic may diagnose an engine fault better than a skilled philosopher; a doctor may read a clinical guideline better than a general reader. Purposeful judgement therefore combines transferable habits with domain knowledge. The transferable habit is asking disciplined questions; the domain knowledge helps you know which questions matter.

## How to avoid the common traps

The most common failure is not lack of intelligence. It is misdirected judgement. People often use reasoning to defend a preferred answer rather than to test whether that answer should be held.

One trap is **performative scepticism**. This looks like critical thinking because it questions claims, but it questions unevenly. It is severe towards disliked claims and generous towards favoured ones. The cure is symmetry: ask the same evidential questions of your own side that you ask of others.

A second trap is **[premature closure]({{ 'premature-closure/' | relative_url }})**. This happens when the first plausible explanation becomes the final explanation. Purposeful judgement keeps alternatives alive long enough to compare them. It does not demand endless doubt, but it resists stopping merely because an answer feels satisfying.

A third trap is **evidence-role confusion**. Twardy’s argument-mapping example shows how learners can confuse explanations with reasons for belief. In everyday settings, the same confusion appears when someone treats a story, analogy, expert impression, correlation, or model as if it provides stronger support than it actually does. Mapping or outlining the argument helps because it forces the question: what is this piece of information doing?<span class="citation-link-wrap"><a class="citation-inline-link" href="https://web-archive.southampton.ac.uk/cogprints.org/3008/1/reasonpaper.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: web-archive.southampton.ac.uk">[University of Southampton Web Archive]</a><span class="citation-popover" role="note"><span class="citation-popover-source">web-archive.southampton.ac.uk</span><span class="citation-popover-snippet">University of Southampton Web Archive</span></span></span>

A fourth trap is **skill without disposition**. People may know how to analyse an argument but avoid doing so when the conclusion threatens identity, status, convenience, or group loyalty. Facione and colleagues argue that teaching for thinking must nurture truth-seeking, open-mindedness, systematicity, intellectual curiosity, confidence in the proper use of reasons and evidence, and maturity of judgement, not only the skills of interpretation, analysis, inference, explanation, and evaluation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.insightassessment.com/var/ezflow_site/storage/pdf/J_Infrml_Ppr%2B_2000%2B-%2BDisp%2B%26%2BSkls.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: insightassessment.com">[Insight Assessment]</a><span class="citation-popover" role="note"><span class="citation-popover-source">insightassessment.com</span><span class="citation-popover-title">Insight Assessment Documents\CT&amp;Cap_Docs\J_Infrml_Ppr.PD F</span><span class="citation-popover-snippet">Insight Assessment Documents\CT&amp;Cap_Docs\J_Infrml_Ppr.PD F</span></span></span>

A fifth trap is **over-formalising every decision**. Purposeful judgement does not mean treating daily life as a courtroom. It means matching the level of scrutiny to the stakes. A casual preference does not need a literature review. A medical decision, legal claim, public accusation, financial commitment, or major career move deserves a much clearer route from evidence to conclusion.

## The practical payoff: better reasons, better revision

Purposeful judgement improves analytical skill because it changes the standard for a good answer. The standard is no longer “Can I defend this?” or “Does this sound smart?” It becomes “Can I show, fairly and proportionately, why this conclusion follows from the best available reasons?”

That standard has two practical payoffs. First, it makes reasoning communicable. Other people can see where they agree, where they disagree, and what evidence would matter. This is especially important in teams, classrooms, public debate, and professional decisions, where hidden reasoning easily becomes conflict over personalities.

Second, it makes revision easier. If a conclusion is tied to a visible route, then new evidence can change the route without humiliating the thinker. A person can say, “I believed this because of A and B; now C weakens B, so I should reduce my confidence.” That is not inconsistency. It is self-regulated judgement working as intended.

The strongest critical thinkers are therefore not the people who never change their minds. They are the people whose changes of mind have reasons. They can explain why they accepted a claim, why they rejected one, why they suspended judgement, and why a later revision was warranted. In that sense, critical thinking is less like having sharper opinions and more like maintaining a reliable intellectual audit trail: a clear account of how a question became a conclusion, and how that conclusion remains open to better evidence.

      var normalized = normalize(languages[i]);
      if (!normalized) continue;
      if (localeMarketMap[normalized]) {
        exactMarket = localeMarketMap[normalized];
        break;
      }
      var languageOnly = normalized.split('-')[0];
      if (!languageMarket && localeMarketMap[languageOnly]) languageMarket = localeMarketMap[languageOnly];
    }
    return { exact: exactMarket, language: languageMarket };
  }
  function inferFromLocale() {
    var matches = localeMatches();
    return matches.exact || matches.language || '';
  }
  function inferFromTimezone() {
    var tz = '';
    try { tz = String(Intl.DateTimeFormat().resolvedOptions().timeZone || ''); } catch (err) {}
    if (!tz) return '';
    for (var i = 0; i< timezoneRules.length; i += 1) {
      var rule = timezoneRules[i] || {};
      try {
        if (new RegExp(rule.pattern).test(tz)) return rule.market;
      } catch (err) {}
    }
    return '';
  }
  function inferMarket(available, options) {
    available = Array.isArray(available) ? available : [];
    options = options || {};
    var storageKey = options.storageKey || 'phoenix-affiliate-market';
    try {
      var saved = window.localStorage && localStorage.getItem(storageKey);
      if (saved && available.indexOf(saved) >= 0) return saved;
    } catch (err) {}
    var timezoneMarket = inferFromTimezone();
    if (timezoneMarket && available.indexOf(timezoneMarket) >= 0) return timezoneMarket;
    var localeMarkets = localeMatches();
    if (localeMarkets.exact && available.indexOf(localeMarkets.exact) >= 0) return localeMarkets.exact;
    if (localeMarkets.language && available.indexOf(localeMarkets.language) >= 0) return localeMarkets.language;
    if (options.defaultMarket && available.indexOf(options.defaultMarket) >= 0) return options.defaultMarket;
    return available[0] || '';
  }
  window.PhoenixAffiliateLocation = {
    normalize: normalize,
    inferMarket: inferMarket,
    inferFromLocale: inferFromLocale,
    inferFromTimezone: inferFromTimezone
  };
})();
