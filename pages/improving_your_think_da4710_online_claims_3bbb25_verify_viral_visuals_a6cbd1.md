## Introduction

Photos and videos often feel like the strongest kind of evidence because they appear to show events directly. Yet a genuine image can still support a false claim if it is shared with the wrong date, location or explanation. A cropped photograph can hide crucial details, an old video can be presented as today's news, and authentic footage from one country can be falsely labelled as another. Before treating a visual post as evidence—or passing it on—it is worth checking not only whether it is real, but also whether it proves what the accompanying caption [claims]({{ 'claims/' | relative_url }}). Professional fact-checkers routinely verify visuals through independent methods rather than accepting them at face value, and many of the same techniques are available to the public.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.invid-project.eu/tools-and-services/invid-verification-plugin/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: invid-project.eu">[InVID project+2Citizen Evidence Lab]</a><span class="citation-popover" role="note"><span class="citation-popover-source">invid-project.eu</span><span class="citation-popover-snippet">InVID projectInVID Verification PluginThe provided tools allow you to quickly get contextual information on Facebook and YouTube videos...</span></span></span>

## Ways Real Visuals Become Misleading

The most common problem is not fabricated imagery but genuine media presented out of context.

A photograph or video can mislead in several ways:

* **Reused from another event.** During wars, natural disasters and protests, years-old footage is frequently recirculated as if it were recorded that day. Reverse image searches often reveal earlier appearances that expose the false timeline.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://citizenevidence.org/2020/01/29/how-to-use-reverse-image-search-for-human-rights-investigations/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: citizenevidence.org">[Citizen Evidence Lab]</a><span class="citation-popover" role="note"><span class="citation-popover-source">citizenevidence.org</span><span class="citation-popover-title">how to use reverse image search for human rights investigations</span><span class="citation-popover-snippet">Citizen Evidence LabHow to: Use Reverse Image Search for Human Rights...29 Jan 2020 — A reverse image search allows an investigator to s...</span></span></span>

<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* **Recaptioned.** A real image may depict one place while the caption claims it was taken somewhere else.
* **Cropped.** Removing parts of a frame can conceal people, signs or actions that change the interpretation.
* **Edited.** Images may be altered by removing, adding or blending elements. Some edits are subtle enough that they require closer inspection.
* **Staged.** A scene may genuinely have been photographed, yet participants deliberately created it for the camera rather than documenting a spontaneous event.
* **Selective.** A short clip may omit what happened immediately before or after, making actions appear justified or unprovoked when the full sequence tells a different story.

</div>

These possibilities mean that authenticity alone is not enough. The key question is whether the visual accurately represents the claim being made about it.

## Reverse Image Search and Geolocation Basics

One of the fastest ways to investigate a suspicious image is a reverse image search. Instead of searching with words, you upload the image or a screenshot so search engines look for visually similar matches.

If an image appeared online months or years before the event it supposedly documents, that is strong evidence that the current claim is misleading. Reverse searches can also uncover higher-resolution originals, news reports, or the account that first published the media. Fact-checkers often search across multiple services because each indexes different parts of the web.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://citizenevidence.org/2020/01/29/how-to-use-reverse-image-search-for-human-rights-investigations/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: citizenevidence.org">[Citizen Evidence Lab+2First Draft]</a><span class="citation-popover" role="note"><span class="citation-popover-source">citizenevidence.org</span><span class="citation-popover-title">how to use reverse image search for human rights investigations</span><span class="citation-popover-snippet">Citizen Evidence LabHow to: Use Reverse Image Search for Human Rights...29 Jan 2020 — A reverse image search allows an investigator to s...</span></span></span>

For videos, searching the whole file is usually less effective. Instead:


<div class="content-enhancement content-enhancement--step-flow" markdown="1">

1. Pause the video at distinctive frames.
2. Capture screenshots showing landmarks, vehicles, clothing or signs.
3. Perform reverse image searches on those individual frames.
4. Compare the results with the claim being made.

</div>

Verification tools such as the InVID-WeVerify browser extension automate much of this process by extracting key frames, displaying metadata where available and linking directly to multiple reverse image search engines.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://weverify.eu/verification-plugin/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: weverify.eu">[WeVerify]</a><span class="citation-popover" role="note"><span class="citation-popover-source">weverify.eu</span><span class="citation-popover-snippet">Verification pluginThe InVID-WeVerify verification plugin is one of the most powerful tools for spotting misinformation online.Re...</span></span></span>

Geolocation adds another layer of checking. Ask whether visible features match the claimed location:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* Do road markings, licence plates or traffic signs fit the country?
* Are mountains, skylines or coastlines consistent with maps or satellite imagery?
* Do shop names, language and architecture match the claimed place?
* Are weather conditions and vegetation plausible for that season?

</div>

You do not always need to identify the exact location. Showing that a claimed location is implausible can already weaken the evidence considerably.

## Context Clues That Change What a Video Proves

Videos often appear persuasive because movement creates a stronger sense of reality than a still photograph. However, context determines what a video actually demonstrates.

Pay attention to:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* **Beginning and ending.** Viral clips often start after the crucial events have already occurred.
* **Original upload date.** An upload timestamp may differ from the date being claimed.
* **Audio.** Music, narration or dubbed speech can dramatically alter interpretation. In some cases, audio has been replaced entirely.
* **Camera perspective.** A single viewpoint may exclude important activity occurring outside the frame.
* **Compression and reposting.** Multiple generations of uploads can remove metadata and visual detail, making forensic analysis harder.

</div>

It is also worth asking whether independent reporting supports the same interpretation. If a dramatic incident genuinely occurred in a public place, multiple photographs, videos or eyewitness accounts often emerge from unrelated sources.

## A Practical Five-Minute Verification Routine

For everyday social media use, you do not need to perform a professional investigation. A short pause before sharing can eliminate many false claims.


<div class="content-enhancement content-enhancement--step-flow" markdown="1">

1. **Read the caption separately from the visual.** Ask what the image itself actually shows.
2. **Search for earlier appearances.** Use reverse image search or screenshots from videos.
3. **Look for the original uploader.** Earlier uploads generally provide more reliable context than widely reshared copies.
4. **Compare with trusted reporting.** Check whether reputable news organisations or established fact-checkers describe the same event in the same way.
5. **Delay sharing if key questions remain unanswered.** Uncertainty is a reason to wait, not a reason to speculate.

</div>

This approach reflects the broader habit of [lateral reading]({{ 'lateral-reading/' | relative_url }}): looking beyond the post itself instead of relying on its presentation or popularity.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://en.wikipedia.org/wiki/Fact-checking" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: Wikipedia">[Wikipedia]</a><span class="citation-popover" role="note"><span class="citation-popover-source">Wikipedia</span><span class="citation-popover-snippet">Open source on wikipedia.org.</span></span></span>

## Why AI Makes Context Checks Even More Important

Generative AI has made convincing synthetic images and videos easier to produce, but experts caution that context remains as important as pixel-level analysis. Many misleading viral posts still rely on older techniques such as recycled footage, deceptive captions or selective editing rather than fully AI-generated media. Verification therefore depends less on spotting visual artefacts than on tracing provenance, comparing independent sources and checking whether the claimed time and place withstand scrutiny.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.theverge.com/tech/888303/photo-video-fake-news-verification-nyt-bellingway" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: theverge.com">[The Verge]</a><span class="citation-popover" role="note"><span class="citation-popover-source">theverge.com</span><span class="citation-popover-snippet">Trusted digital investigators like The New York Times, Bellingcat, and Indicator rely on rigorous verification protocols to discern real...</span></span></span>

Rather than asking, "Does this look real?", a stronger analytical habit is to ask, "What exactly does this visual prove, and what independent evidence supports that conclusion?" That shift turns an emotionally compelling post into a claim that can be tested instead of merely believed.

        break;
      }
      var languageOnly = normalized.split('-')[0];
      if (!languageMarket && localeMarketMap[languageOnly]) languageMarket = localeMarketMap[languageOnly];

  }

    var matches = localeMatches();

  }
  function inferFromTimezone() {
    var tz = '';
    try { tz = String(Intl.DateTimeFormat().resolvedOptions().timeZone || ''); } catch (err) {}
    if (!tz) return '';
    for (var i = 0; i< timezoneRules.length; i += 1) {
      var rule = timezoneRules[i] || {};
      try {
        if (new RegExp(rule.pattern).test(tz)) return rule.market;
      } catch (err) {}
    }
    return '';
  }

    options = options || {};

    try {

      if (saved && available.indexOf(saved) >= 0) return saved;
    } catch (err) {}

    var localeMarkets = localeMatches();
    if (localeMarkets.exact && available.indexOf(localeMarkets.exact) >= 0) return localeMarkets.exact;
    if (localeMarkets.language && available.indexOf(localeMarkets.language) >= 0) return localeMarkets.language;
    if (options.defaultMarket && available.indexOf(options.defaultMarket) >= 0) return options.defaultMarket;
    return available[0] || '';
  }

    inferFromLocale: inferFromLocale,
    inferFromTimezone: inferFromTimezone
  };
